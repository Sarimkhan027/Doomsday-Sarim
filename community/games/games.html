The honest briefing

A playable browser demo—not online multiplayer yet.

The arena runs on each visitor’s own browser, so sharing this page lets friends play their own practice run. Live matches between players, persistent accounts, and real Facebook / Google / Twitter authentication need a game server and provider credentials.
